# VELORA

### Define Your Style. Own Your Identity.

VELORA is a modern fashion e-commerce website designed to deliver a premium and minimal shopping experience. Built using HTML, CSS, JavaScript, Supabase, and Razorpay.

🌐 **Live Website:** https://the-velora.netlify.app

---

## Features

- Modern, responsive fashion website
- Men's and Women's collections
- New Arrivals section
- Product details and size selection
- Shopping cart and wishlist
- User signup and login
- My Orders dashboard
- Cash on Delivery (COD)
- Online payments with Razorpay
- Supabase database integration
- Admin dashboard for product management

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Supabase
- Razorpay
- Netlify

## Project Structure

- `index.html` – Homepage
- `men.html` – Men's collection
- `women.html` – Women's collection
- `cart.html` – Shopping cart
- `checkout.html` – Checkout page
- `my-orders.html` – Order history
- `admin.html` – Admin dashboard
- `admin-products.html` – Product management
- `css/` – Stylesheets
- `js/` – JavaScript files
- `images/` – Website images

## Payment Methods

- Razorpay Online Payment
- Cash on Delivery

## Deployment

The website is deployed using Netlify.
